# Tata GenAI Powered Data Analytics Job Simulation

## 📌 Project Overview

This repository contains my work completed as part of the **Tata GenAI Powered Data Analytics Job Simulation** on Forage.

The project demonstrates an end-to-end analytics workflow in a financial services context, covering:

**Exploratory Data Analysis → Predictive Modeling → Business Recommendations → AI-Powered Collections Strategy**

---

## 🎯 Project Objectives

- Analyze customer data and identify patterns related to delinquency.
- Explore key risk factors through exploratory data analysis.
- Develop a conceptual predictive model for identifying high-risk customers.
- Translate analytical insights into actionable business recommendations.
- Design a responsible AI-powered collections system with human oversight and ethical guardrails.

---

## 📂 Project Tasks

### 📊 Task 1: Exploratory Data Analysis (EDA)

Conducted exploratory data analysis to understand customer data, identify data quality considerations, and explore patterns associated with delinquency.

- Data Visualization
- Data Cleaning and Interpretation

### 📈 Task 3: Business Recommendations

Translated predictive insights into a stakeholder-focused business report.

## ⚖️ Responsible AI Considerations

Responsible AI principles were incorporated throughout the project, including:

- **Fairness:** Monitoring for potential bias across customer groups.
- **Explainability:** Making AI-driven decisions understandable to stakeholders.
- **Human Oversight:** Escalating complex or high-impact decisions for human review.
- **Transparency:** Maintaining clear decision logic and documentation.
- **Compliance:** Designing appropriate safeguards for responsible financial decision-making.
